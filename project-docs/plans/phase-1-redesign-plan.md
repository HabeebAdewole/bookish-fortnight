# Phase 1 — expressive FORM landing redesign

## Agreed goal

Replace the restrained initial landing page with a playful, illustrated fitness-club identity. The user approved the proposed direction after a review of Cardtonic Upskill. Learn from broad layout and interaction principles; create original art, composition, copy, palette, and timing.

## Visual system

- Ink #202320, warm white #FFF9ED, orange #FF7446, sky #A8D8F0, pale yellow #F1E7A1. Use ink text on bright accents.
- Barlow Condensed 800 for athletic display typography; DM Sans for body and controls. Self-host both fonts and retain their licenses in project documentation.
- Oversized centered hero heading with original human fitness illustration, short supporting copy, and a clear class CTA. Small running-track curves provide the connecting visual motif.
- Light class-discovery section with colourful, horizontally browsable cards; retain the read-only category-filtered weekly schedule below.
- Dark first-session guide, sky-blue community/trainer section, light membership comparison, orange closing section.
- Use a short scroll-linked hero depth effect on desktop, section entry treatment for the first-session sequence, and responsive feedback on buttons/cards. No continuous distracting decorative loops. Reduced-motion preference removes movement.

## Review

The gym-specific artwork, weight-plate graphics, running-track arcs, and condensed sports typography distinguish FORM from the reference. Do not copy the reference's character, display font, hanging-card cable, section composition, or exact palette. Keep core information easy to read without animation. Use actual buttons for carousel controls and respect touch and keyboard input.
