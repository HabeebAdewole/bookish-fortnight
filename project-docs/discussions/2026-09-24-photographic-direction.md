# FORM — gym-first design and media review

## User direction

The illustrated landing page is visually appealing but does not sufficiently represent a gym. The user requested an Equinox-inspired, photography/video-led site, asked for page-by-page design research, then supplied Dribbble, Unsplash, Pexels, and Lucide references. Licensed stock sourcing was explicitly selected.

## Equinox review coverage

Inspected home, membership benefits, group fitness, a strength-class detail page, personal training, Pilates, club finder, membership enquiry, and the first join step. Reviewed loaded desktop sections, media attributes, and navigation. The club finder did not return a usable club list during this inspection, so individual location pages were not assessed. No claim is made to have reviewed every location, article, policy, shop, or hotel page.

Key observed principles: large photographic/video sections; restrained monochrome typography; service-specific pages; training and facility imagery; asymmetric image arrangements; clear membership and visit routes. Homepage and several service pages use muted looping video. FORM should borrow these broad principles while creating original composition, copy, media selection, and motion.

Sources: https://www.equinox.com/ ; /memberbenefits ; /groupfitness ; /groupfitness/strength ; /personaltraining ; /pilates ; /clubs ; /membership ; /join/step1.

## Proposed page system

1. Home: cinematic training hero, class formats, coaching, facilities, and membership overview.
2. Classes and weekly schedule: discipline/day/trainer filters, duration and intensity, clear empty states, class details.
3. Trainers: consistent portrait treatment, specialties, and links to individual profiles.
4. Trainer profile: biography, approach, specialities, and related sample sessions; fictional content clearly identified.
5. Membership: transparent sample prices, inclusions, comparison, and FAQs. No fabricated offers or checkout.
6. About / The Club and Contact: facilities, training philosophy, visit information. Do not invent a real address or operational contact channel.
7. Login and signup: visual direction may be prepared now; working auth remains Phase 3.

## FORM translation

Retain the name and wordmark. Replace the illustration-led opening with licensed real photography/video. Use near-black, white, cool greys, and a small controlled brand accent. Keep headings deliberate and readable rather than uniformly oversized. Use concrete gym language: strength training, conditioning, mobility, coaching, class duration, equipment, and membership access.

Improve usability with clear schedule filters, transparent prices, visible pause/play controls, reduced-motion and data-conscious video behavior, a static poster fallback, and useful mobile layouts. Prefer substantive service information over imitation luxury claims.
